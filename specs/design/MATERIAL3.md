# Material 3 Rules

Source:
https://m3.material.io/

Design Language:
Google Workspace

Principles:

-   Clean
-   Functional
-   Minimal
-   Accessible

Use:

Navigation:

-   Top App Bar
-   Navigation Rail
-   Side Navigation

Data:

-   Table
-   List
-   Cards only when necessary

Forms:

-   Filled inputs
-   Single-column first

Density:
Compact

Shape:
Medium

Elevation:
Level 0–2 only

Spacing:
8pt grid

Typography:
Google Sans Flex (superseded Roboto — see TOKENS.md § Typography)

Motion:
Subtle

Avoid:

-   Large hero
-   Glassmorphism
-   Heavy gradients
-   Excessive cards
-   Decorative animation
-   Floating widgets
